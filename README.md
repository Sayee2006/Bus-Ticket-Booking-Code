🚌 Bus Ticket Booking App (Python)
A simple and beginner-friendly Python program that allows users to select a bus route, choose the number of tickets, calculate the total amount, and save the ticket details into a text file.
This project is great for beginners who want to practice:
Dictionaries
Conditionals
User input
File handling
Basic Python logic

🚀 Features

✔ Shows a list of available bus routes
✔ Lets the user select a route
✔ Calculates total price based on number of tickets
✔ Saves ticket details to ticket.txt
✔ Beginner-friendly and easy to modify

📂 Project Structure

Bus-Ticket-Booking/
│
├── bus_ticket.py        # Main Python program
└── ticket.txt           # Auto-generated ticket file


---

🛠 How to Run

1. Make sure Python is installed on your system.


2. Download or clone this repository:

git clone https://github.com/your-username/Bus-Ticket-Booking.git


3. Navigate to the project folder:

cd Bus-Ticket-Booking


4. Run the Python file:

python bus_ticket.py
